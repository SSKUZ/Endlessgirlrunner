# GIRL V2 / BOY V2 — восстановление и проверка

Модели сохранены в `v2_parts/parts/` небольшими бинарными частями. Исходные
V1 и их части не изменены. Для восстановления GLB достаточно стандартного
Python 3, дополнительные библиотеки не нужны:

```sh
python assets/characters/restore_v2.py
python assets/characters/verify_characters_v2.py
```

Будут созданы:

- `assets/characters/girl_avatar_v2.glb`
- `assets/characters/boy_avatar_v2.glb`

Скрипт проверяет SHA-256 и размер каждой части, объединённого gzip-потока и
итогового GLB, затем атомарно записывает результат. Манифест параметров моделей:
`manifest_v2.json`. Полный манифест частей: `v2_parts/manifest.json`.

## Первоначальные результаты предыдущих сессий

В `recovery_v2/` сохранены первоначальные V2 до новых правок по ТЗ №3.3.
Их восстановление не заменяет доработанные файлы:

```sh
python assets/characters/restore_v2.py --recovery
```

Результат находится в `recovery_v2/restored/`. Исходные контрольные изображения
сохранены в `recovery_v2/qa/`. Начальная версия генератора доступна в контрольном
коммите `e1f2ef64e9a242f6e94cbace056ad4ff8b387204`.

## Воспроизводимая сборка

Сначала восстановить V1 из неизменённых исходных частей, затем использовать
сохранённый генератор переработки:

```sh
python -m pip install -r tools/requirements-characters.txt
python assets/characters/restore_characters.py
python tools/redesign_characters.py
python tools/package_characters_v2.py
python assets/characters/verify_characters_v2.py
python tools/render_character_qa.py
```

Для контрольной суммы существующего сохранённого GLB используйте восстановление
из частей. Повторный экспорт с другой версией зависимостей может изменить
порядок сериализации при той же геометрии.

## Визуальные результаты

В `qa_v2/` представлены реальные рендеры экспортированных GLB: спереди, сзади,
слева, справа, лицо и волосы. Два файла `*_contact.jpg` показывают все ракурсы.
JPEG сохранены в GitHub; при повторном рендере также создаются PNG.

Техническая целостность — **PASS**. Художественное качество и портретное
сходство — **PARTIAL**: волосы остаются скульптурно упрощёнными, нос, губы и
мимика ещё не достигают присланного образца семейной 3D-анимации.
